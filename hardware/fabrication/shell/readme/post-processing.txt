Tools:
- Pliers for supports
- File / sandpaper 180 and 320 grit
- Tweezers

General:
- Remove stringing
- Check faults
- Lightly sand flat mating surfaces, avoid small features
- Remove support nubs

Bottom Plate:
- Has ribs/pockets to stop wobble. Sand lens socket so lens drops clean.
- Clear screw holes with 2mm drill by hand if needed.

PCB-Holder:
- Small clip on top of bottom shell near MCU, holds board down so it won't lift.
- Sand edges until it clips firmly, not loosely.

Scroll Wheel:
- Sand rough edge from seam hard, and small pad that presses middle switch.

Side Buttons:
- Sand front faces where thumb touches, sand inner rails if sticky.

Top Shell and Plunger Studs:
- Studs are ~2mm blocks clipped onto underside of top shell into 2 holes under large plungers. These click onto LMB/RMB switches. Shortest RMB longest LMB.
- Ensure studs fully seated, plungers move freely.

Final:
- Assemble without feet first, test clicks and scroll, then add feet. Flash binary from firmware/build/ before closing top shell. Test at https://realsynarix.github.io/Cobalt-X-Zero/.
