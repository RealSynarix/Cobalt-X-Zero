Flash firmware in 30 seconds

No drivers. No terminal. The MCU exposes a USB drive in DFU mode.

1

Enter DFU

Hold the tiny DFU button on the PCB, then plug the mouse in. Keep holding for 2 seconds. A drive named COBALT-DFU should appear.

2

Copy firmware

Drag the .bin file onto that drive. Or use STM32CubeProgrammer: connect, open file, click Start Programming. Wait until it says success.

3

Done

Unplug, then plug back without holding DFU. The configurator should reconnect automatically.

Download firmware .bin

If the drive does not show, try another cable and hold DFU before USB is powered. Firmware file is a placeholder until you link your release. Keep VID 0x1209 PID 0xC0BA in the binary descriptors.

Troubleshooting

  • Chrome required: WebHID only works in Chromium over HTTPS. GitHub Pages is fine.
  • If device shows as "Access denied", close other apps that may hold the HID handle and reload.
  • Do not flash while Apply All is running. Finish writes first.
